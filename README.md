Minimal repository for the paper "A Unified Taxonomy for Investigating the Mechanisms of Multilingual MultiModal Misinformation" (https://arxiv.org/abs/2608.29681).

It contains the prompt we have used and the resulting dataset annotated using the VLM, as described in the paper. The dataset we publicly release does not contain identifiable information such as user names, the tweet content, or the images themselves. Please contact us if you need it.
